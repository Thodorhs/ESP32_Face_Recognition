# ESP32_Face_Recognition
ESP32-S3 TinyML Face Recognition with complete end-to-end machine learning pipeline and embedded C/C++ firmware

## Description

This repository contains the complete end-to-end machine learning pipeline and embedded C/C++ firmware for a Face Recognition "Smart Lock" system. Developed for the Seeed Studio XIAO ESP32-S3 Sense, the system captures image data, processes it locally using a quantized TensorFlow Lite Micro (TFLM) model, and verifies the identity of team members in real-time. The project includes custom data collection scripts, a Python-based training and optimization pipeline, and an ESP-IDF deployment application built for highly resource-constrained edge execution.
